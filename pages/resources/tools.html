ARIA Data Pipeline

Pipelines automatizados para coleta, validação e integração de dados epidemiológicos

O que é

  • Sistema API-first desenvolvido em Python para processamento de dados epidemiológicos
  • Integração com fontes de dados de saúde em tempo real
  • Pipeline escalável para grandes volumes de dados

Como funciona

  • Processa dados de saúde em tempo real
  • Valida e padroniza dados de múltiplas fontes
  • Disponibiliza dados via API para análise

Repositório

  • github.com/isarichub/aria-pipeline

CREDO Analytics Suite

Ferramentas para análise estatística e visualização de dados clínicos

O que é

  • Suite de análise estatística para dados clínicos

Como funciona

Predictive Models Framework

Ferramentas para desenvolvimento e validação de modelos preditivos em epidemiologia

O que é

  • Framework para desenvolvimento de modelos preditivos
  • Validação de modelos com dados históricos
  • Integração com variáveis climáticas e de mobilidade

Como funciona

  • Treinamento de modelos com dados históricos
  • Validação cruzada e métricas de desempenho
  • Deploy de modelos via API
