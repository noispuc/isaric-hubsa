Visual Evidence & Research Tool for Exploration

🟢 Disponível

Sobre o VERTEX

O VERTEX (Visual Evidence & Research Tool for Exploration) é uma aplicação web baseada em Python que apresenta gráficos e tabelas para responder rapidamente a perguntas de pesquisa durante surtos. A ferramenta auxilia na identificação de fatores epidemiológicos chave e apoia a tomada de decisão baseada em dados.

Desenvolvido pelo ISARIC, o VERTEX é open-source e está disponível no GitHub. Ele se integra perfeitamente ao ecossistema de ferramentas ISARIC, utilizando dados capturados pelo ARC (para padronização de formulários) e gerando análises a partir de bancos de dados REDCap.

Funcionalidades Principais

🌍 Mapa Global

Visualização geográfica do número de pacientes e países incluídos no banco de dados.

📊 Painéis de Análise

Conjuntos de gráficos e tabelas organizados por perguntas de pesquisa específicas.

🔄 Pipeline Analítico Reprodutível

Baseado no conceito de Reproducible Analytical Pipelines (RAPs), garantindo reprodutibilidade, eficiência e auditoria das análises.

📁 Projetos Estáticos e Dinâmicos

Suporta projetos que executam análises diretamente de bancos de dados REDCap (via API) ou que reproduzem figuras a partir de dados agregados.
