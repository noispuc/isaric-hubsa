ARC – Analysis and Research Compendium

O ARC (Analysis and Research Compendium) é uma biblioteca abrangente de perguntas harmonizadas, projetada para construir rapidamente formulários de relato de caso (CRFs) padronizados para surtos de doenças. Ele cobre uma ampla gama de informações relacionadas ao paciente, incluindo dados demográficos, comorbidades, sinais e sintomas, medicamentos, desfechos e muito mais.

Cada pergunta no ARC possui diretrizes específicas e parâmetros relevantes, como definições, opções de resposta, unidades, limites mínimos e máximos, tipos de dados e lógica de salto.

✓ Legível por máquinas

Disponível em formato CSV, facilitando a leitura e o processamento automatizado.

✓ Acesso aberto

Livremente acessível para a comunidade científica.

✓ Controle de versão

Mantido via GitHub, garantindo integridade, rastreabilidade e colaboração.

✓ Integração com BRIDGE

O ARC é integrado ao BRIDGE, nossa ferramenta para geração de CRFs.

Componentes do ARC

  • arc.csv – Lista legível por máquinas de perguntas clínicas e de pesquisa.
  • Lists/ – Coleção de listas de opções padronizadas (condições, dados demográficos, medicamentos).
  • Data Capture Schema – Estrutura de dados que define os momentos-chave na jornada do paciente.
🔗 Ver no GitHub

BRIDGE

O BRIDGE é uma aplicação web desenvolvida pelo ISARIC que auxilia na criação de formulários de relato de caso (CRFs) com base no ARC. A ferramenta permite selecionar e personalizar perguntas clínicas, adaptando os CRFs ao contexto específico de cada surto.

Com o BRIDGE, é possível gerar automaticamente dicionários de dados e arquivos XML para criação de bancos de dados REDCap, versões para impressão dos CRFs e guias de preenchimento.

Componentes do BRIDGE

  • 1. Barra de Ferramentas – Acesso às configurações e templates.
  • 2. Árvore do ARC – Apresenta o ARC como uma estrutura em árvore (versões, formulários, seções e perguntas).
  • 3. Painel de Representação do CRF – Visualização do formulário gerado.
